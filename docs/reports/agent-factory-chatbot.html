明白。我把它编译成一个新的声明式 agent（薄 loop + 复用 Inngest harness），接进招聘域现有事件图，全程过六层门禁，最后由你批准上线。计划如下：

理解的计划
  1. 从招聘本体派生 referenceCheck skill（how-to + 工具 + I/O schema）
  2. 生成时裁剪工具箱（背调相关 typed tools）
  3. 接事件：INTERVIEW_PASSED → 本 agent → REFERENCE_CHECK_PASSED / _FLAGGED
  4. 静态校验事件图闭合 + 沙箱 dry-run + 离线 eval（pass^k）
  5. 结果汇总，等你批准 draft→active

开始执行，过程在右侧"推理 / 事件图 / 校验"面板同步。
